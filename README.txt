THIỆP 20/10 GỬI TRANGG CUTEE — TỪ TIẾN 💗

CÁCH XEM THỬ
1. Giải nén ZIP.
2. Giữ index.html và cả 3 ảnh JPG trong cùng thư mục.
3. Mở index.html bằng Chrome hoặc Edge.

CÁCH ĐƯA LÊN INTERNET ĐỂ TẠO QR
1. Tạo repository GitHub mới, ví dụ thiep-20-10.
2. Upload index.html và cả 4 ảnh lên repository, cùng cấp.
3. Vào Settings > Pages.
4. Chọn Deploy from a branch, branch main, folder /(root), rồi Save.
5. Chờ GitHub Pages công bố website; mở thử link trên điện thoại.
6. Tạo mã QR từ link đã hoạt động.

Sửa lời chúc: mở index.html bằng VS Code.
Ảnh: thay file nhưng giữ nguyên tên trangg-camera.jpg, trangg-sunflower.jpg,
trangg-stars.jpg, bo-hoa-tien-tang.jpg. Ai có link website đều có thể xem nội dung và ảnh.
